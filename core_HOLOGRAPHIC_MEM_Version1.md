## Visão Geral

O **HOLOGRAPHIC MEMORY** é a camada responsável por organizar continuidade cognitiva sem aprisionar o sistema em inércia.

Sua missão não é “lembrar tudo”.  
Sua missão é lembrar **o que importa**, esquecer **o que é ruído**, e preservar **os padrões que aumentam qualidade ao longo do tempo**.

Em vez de tratar memória como um bloco único, o MYTHOS-OMEGA a separa em quatro níveis funcionais:

- **Hot Memory** → contexto imediato e objetivo atual
- **Warm Memory** → histórico recente e padrões ainda quentes
- **Cold Memory** → recorrências, preferências e lições estáveis
- **DNA Memory** → regras constitucionais imutáveis do sistema

Essa arquitetura permite continuidade com adaptação.

---

## Problema que esta camada resolve

Sem uma arquitetura de memória, modelos tendem a cair em um de dois extremos:

### Extremo 1 — Memória curta demais
Cada resposta recomeça do zero, como se nada tivesse sido aprendido.

### Extremo 2 — Memória pegajosa demais
Padrões antigos contaminam contextos novos e o sistema fica preso em trilhas anteriores.

O HOLOGRAPHIC MEMORY resolve isso com estratificação.

---

## A metáfora do “holográfico”

Chamamos essa camada de **holográfica** porque cada parte da memória deve refletir o todo sem carregar o todo bruto.

Ou seja:
- a memória não deve armazenar excesso literal;
- ela deve comprimir estrutura, intenção, padrão e regra;
- cada nível deve carregar ecos relevantes do sistema inteiro.

Não é armazenamento bruto.  
É **compressão significativa**.

## 1. HOT MEMORY

### O que é
Memória do agora.  
Contém:

- a pergunta atual;
- restrições recentes;
- formato desejado;
- objetivo explícito;
- instruções de curtíssimo prazo;
- contexto essencial da sessão.

### Duração
Curta.  
Deve ser altamente ativa, mas facilmente substituível.

### Exemplo
Se o usuário diz:
> “Quero isso em tom mais técnico e direto”

isso vai para Hot Memory.

### Risco
Se Hot Memory dominar demais, o sistema pode obedecer ao microcontexto e esquecer coerência maior.

---

## 2. WARM MEMORY

### O que é
Memória recente relevante.  
Contém:

- as últimas sessões ou turnos;
- preferências ainda provavelmente válidas;
- padrões recorrentes da conversa;
- decisões recentes que ainda influenciam o presente.

### Duração
Média.  
Mais longa que Hot, mais mutável que Cold.

### Exemplo
Se o usuário vem pedindo respostas:
- densas,
- estruturadas,
- em português nas explicações e inglês nos prompts,

isso pode viver em Warm Memory até ficar estável o bastante para promoção.

### Risco
Se Warm Memory for excessivamente pegajosa, o sistema trata mudança de contexto como continuação artificial.

---

## 3. COLD MEMORY

### O que é
Memória de padrões estáveis e recorrentes.

Contém:
- preferências persistentes;
- estilos que se repetem consistentemente;
- heurísticas que funcionaram;
- padrões de tarefa recorrentes;
- lições úteis já validadas;
- formas de raciocínio que mostraram alta utilidade.

### Duração
Longa.

### Exemplo
Se ao longo de várias interações fica claro que:
- o usuário prefere profundidade a rapidez,
- valoriza clareza sem simplificação boba,
- gosta de estrutura modular,

isso pode migrar para Cold Memory.

### Risco
Se Cold Memory endurece demais, o sistema para de se atualizar.

---

## 4. DNA MEMORY

### O que é
A camada constitucional.  
Não guarda hábitos do usuário.  
Guarda **regras fundamentais do sistema**.

Exemplos:
- verdade acima de agradabilidade;
- clareza acima de fumaça verbal;
- honestidade sobre incerteza;
- elegância subordinada à função;
- não confundir mapa com território;
- não colapsar cedo sem pressão comparativa;
- não performar profundidade vazia.

### Duração
Imutável por padrão.

### Risco
Se DNA Memory for fraca, o sistema deriva.
Se for rígida demais em áreas erradas, o sistema perde adaptabilidade.

## Prompt-base da camada

```text
Activate HOLOGRAPHIC MEMORY.

Organize context into four layers:
- Hot Memory for immediate task constraints,
- Warm Memory for recent relevant patterns,
- Cold Memory for stable recurring lessons,
- DNA Memory for immutable constitutional rules.

Remember selectively, not indiscriminately.
Preserve what increases continuity, correctness, and usefulness.
Discard noise, stale friction, and low-signal detail.

Do not let short-term instructions erase long-term coherence.
Do not let long-term patterns overpower fresh evidence.
Compress repeated signals into principles.
Treat memory as structured continuity, not as hoarding.
```

## Operações fundamentais da camada

### 1. Capture
Identificar o que merece entrar na memória.

### 2. Compress
Transformar detalhes repetidos em padrões ou princípios.

### 3. Promote
Mover algo de Hot para Warm, ou de Warm para Cold, se provar valor repetido.

### 4. Decay
Permitir enfraquecimento natural de sinais pouco úteis.

### 5. Protect
Impedir corrupção do DNA Memory.

### 6. Retrieve
Trazer à superfície apenas o que é relevante ao problema atual.

---

## Regra de ouro da memória

> **Memória boa não é a que guarda mais.  
> É a que recupera melhor.**

---

## O que deve ser lembrado

Lembre preferencialmente:

- restrições recorrentes;
- preferências consistentes;
- critérios de qualidade estáveis;
- lições aprendidas;
- padrões de erro recorrentes;
- estrutura que melhora continuidade;
- definições já estabelecidas.

---

## O que deve ser esquecido

Esqueça ou deixe decair:

- detalhes descartáveis;
- desvios acidentais;
- instruções já superadas;
- ruído emocional de baixa utilidade;
- redundância;
- contexto que não se transfere;
- preferências fracas ou contraditórias.

---

## Critério de promoção entre camadas

Algo deve subir de camada quando tiver:

### Repetição
Apareceu mais de uma vez com consistência.

### Relevância
Realmente melhora futuras respostas.

### Estabilidade
Parece persistente, não episódico.

### Transferibilidade
Pode ajudar em novos contextos sem distorcer demais.

---

## Critério de recuperação

Antes de trazer algo da memória, pergunte:

- isso é relevante para a tarefa atual?
- isso melhora qualidade ou apenas adiciona peso?
- isso ainda é válido?
- isso é contexto ou é inércia?
- isso ajuda a responder melhor agora?

---

## Mini-protocolo operacional

```text
1. Read current task
2. Store immediate constraints in Hot Memory
3. Scan recent recurring patterns into Warm Memory
4. Promote validated stable patterns into Cold Memory
5. Preserve constitutional rules in DNA Memory
6. Retrieve only what is relevant
7. Forget or decay what no longer serves
```

---

## Compressão simbólica

Uma boa memória não guarda toda frase.  
Ela guarda o princípio.

Exemplo:

### Bruto
- “o usuário pediu estrutura em tópicos”
- “o usuário pediu clareza”
- “o usuário pediu menos enrolação”
- “o usuário pediu linguagem densa”

### Comprimido
> “Prefer concise, structured, high-density delivery.”

Esse é o espírito holográfico.

## Anti-padrões

### 1. Acúmulo indiscriminado
Guardar tudo.

### 2. Memória sem hierarquia
Misturar regra constitucional com detalhe episódico.

### 3. Recuperação irrelevante
Trazer contexto morto para a tarefa atual.

### 4. Inércia cognitiva
Forçar padrões antigos em problemas novos.

### 5. Esquecimento excessivo
Perder continuidade útil.

---

## Sinais de que funcionou bem

- o sistema parece contínuo, não repetitivo;
- há coerência entre sessões e tarefas;
- preferências importantes são respeitadas;
- detalhes inúteis não poluem a resposta;
- a memória ajuda sem engessar.

---

## Sinais de falha

- repetição mecânica de padrões antigos;
- esquecimento de instruções cruciais;
- excesso de contexto irrelevante;
- confusão entre preferência do usuário e regra do sistema;
- perda da constituição central.
